# 💰 Smart Expense Tracker

A web-based expense management application built using Python Flask and SQLite.

## 📌 Project Overview

Smart Expense Tracker helps users record, manage, analyze, and monitor their daily expenses through a simple web interface.

The application provides expense tracking, category-wise analysis, monthly spending visualization, budget planning, budget alerts, and expense insights.

## 🚀 Features

- ➕ Add new expenses
- ✏️ Edit existing expenses
- 🗑️ Delete expenses
- 🔎 Search expenses by category or description
- 💰 Monthly budget planner
- 🚨 Budget alerts
- 📊 Category-wise spending analysis
- 📈 Spending charts
- 📅 Monthly spending analysis
- 💡 Expense insights
- 🧾 Expense history
- 📱 Responsive web interface

## 🛠️ Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- Chart.js
- Jinja2
